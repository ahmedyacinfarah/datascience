# Dataset Exploration Assignment

This repository contains an exploratory study of two Kaggle datasets from
different domains, completed as part of a data science assignment.
The goal is to analyze and understand the structure and characteristics
of each dataset.

## Dataset 1 — Healthcare
- **Name:** Heart Failure Prediction Dataset
- **Domain:** Healthcare
- **Size:** 918 rows, 12 features
- **Description:** Clinical and demographic data used to predict heart disease events.
- **Source (Kaggle):**
  https://www.kaggle.com/datasets/fedesoriano/heart-failure-prediction/data

## Notes
- Datasets are not stored directly in this repository.
- Raw data files are downloaded locally from Kaggle and excluded using `.gitignore`.
- This repository contains notebooks and documentation only.
