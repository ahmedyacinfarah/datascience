# Data Sources

The raw datasets used in this project are not stored directly in this
repository. They are downloaded locally from Kaggle and excluded using
`.gitignore`.

## Dataset 1 — Healthcare
- **Name:** Heart Failure Prediction Dataset
- **Source:** Kaggle
- **Link:** https://www.kaggle.com/datasets/fedesoriano/heart-failure-prediction/data
- **Description:** Clinical and demographic data used for heart failure prediction.

## Dataset 2 — Automotive / Transportation
- **Name:** Cars Europe Dataset
- **Domain:** Automotive / Transportation
- **Size:** 25 features (columns), [rows depend on dataset, usually ~1000+]  
- **Description:** This dataset contains European car listings with features such as brand, model, fuel type, transmission, body type, year, mileage, engine power, and price. It provides a rich mix of numerical and categorical features, making it ideal for exploratory analysis.  
- **Source (Kaggle):** https://www.kaggle.com/datasets/alemazz11/cars-europe/data
